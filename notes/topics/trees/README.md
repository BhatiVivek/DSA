## Where to put new notes

Your initial Trees notes are organized by subject so each file can grow as you learn.

| If your new notes cover... | Update this file |
| --- | --- |
| Definitions, terminology, properties, node representation | [fundamentals.md](fundamentals.md) |
| Tree categories and their rules | [types-of-trees.md](types-of-trees.md) |
| Traversal orders, DFS/BFS mechanics, zigzag, traversal complexity | [traversals.md](traversals.md) |
| A reusable way to solve problems, such as combining child results | [tree-dfs.md](../../patterns/tree-dfs.md) |
| Your attempt at one specific problem, mistakes, and solution | A new note under [practice/trees](../../../practice/trees/README.md), using the [problem template](../../../templates/problem.md) |

To update notes:

1. Open the matching file and expand the relevant section with your explanation, example, or code.
2. If it is a substantial new subtopic, create a sibling file such as `binary-search-trees.md` and add its link under **Notes** above.
3. Put reusable problem-solving approaches in `notes/patterns/` and link them from here.
4. Put actual problem attempts in `practice/trees/` and record them in the [practice log](../../../practice/README.md).
5. Check roadmap items when you can explain or implement them yourself. Having written notes does not automatically mean a topic is mastered.

The maximum-depth code from your initial notes is included in the DFS pattern as a worked example. Create a separate practice note when you attempt that problem yourself.
