# Note templates

Copy a template to its destination, rename it, and replace the placeholders. Remove sections that do not help with that note.

| Template | Destination | Use it for |
| --- | --- | --- |
| [Topic](topic.md) | `notes/topics/<topic>/README.md` | Concepts, a learning checklist, and related notes |
| [Pattern](pattern.md) | `notes/patterns/<pattern-name>.md` | Recognizing and applying a recurring approach |
| [Problem](problem.md) | `practice/<topic>/<problem-name>.md` | Reasoning, solution, mistakes, and revision |

Examples: `notes/topics/graphs/README.md`, `notes/patterns/two-pointers.md`, `practice/trees/maximum-depth.md`.

Link new notes from their topic or pattern index so they are easy to find on GitHub.
